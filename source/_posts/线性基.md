# 什么是线性基？
就是线性代数的那个基。所谓“某某题是线性基”，就是说这个题的做法是把线性基搞出来，然后怎么糊一下出答案。

# 拿线性基干什么？
目前看到的经典且常见的用法是求某几个数的**最大或第 $k$ 小异或和**。

# 经典例题

## [求最大异或和（P3812 【模板】线性基）](https://www.luogu.com.cn/problem/P3812)

什么鬼捏？

你把这些数转成二进制，然后把每个数都看成一个向量，每个数的每一个 $1$ 或 $0$ 看成向量里面的一个元素。

于是问题就转化成了 如何通过一系列异或式的线性变换 使向量的元素组成的数最大。

但是发现现在这个问题仍然不好做，因为目前向量极有可能是 **线性相关** 的，在试图处理最大值时，向量间会相互影响（目前这么说有些难懂，下文举个例子）

所以说呢，我们就可以把向量们的 **线性基** 给整出来，用 基向量 不仅能表示出相同的线性空间，还满足了向量间线性无关，就好操作了。

具体基向量怎么个处理法呢？共两种方法：
1. 用高斯消元。

    我们试图 **从向量的高位往低位（这是重点）** 高斯消元，消出来最多的 基向量（或者说就叫求秩）。

    注意到了吗？假设最后的基向量有 $k$ 个（这个样例中 $k=n$），那么最后高斯消元消出来后，基向量前面一部分 “大概” 看一下，每一位在 $k$ 个向量中成为一次 $1$。此时我们把所有基向量都异或起来，前一部分就做到了 “差不多” 全是 $1$，就做到了找到最大异或和。

    为什么说 ”差不多“ 呢？因为向量前几位中可能出现 **取不到 $1$** 或 **消不出来** 的情况，但其实无所谓，不会影响最后的答案是对的:

    回到上文,如果不消成基向量,你无法控制那些 $1$ 是取得到还是取不到。可能你本身 $1$ 都取到了,结果又异或上一个向量又变成 $0$ 了。

    高斯消元法代码：
    ``` cpp
    #include <iostream>
    #include <cstring>
    #include <algorithm>

    using namespace std;

    typedef long long LL;
    const int N = 100010;

    int n;
    LL a[N];

    int main()
    {
        scanf("%d", &n);
        for (int i = 0; i < n; i ++ ) scanf("%lld", &a[i]);

        int k = 0;
        for (int i = 62; i >= 0; i -- )
        {
            for (int j = k; j < n; j ++ )
                if (a[j] >> i & 1)
                {
                    swap(a[j], a[k]);
                    break;
                }
            if (!(a[k] >> i & 1)) continue;
            for (int j = 0; j < n; j ++ )
                if (j != k && (a[j] >> i & 1))
                    a[j] ^= a[k];
            k ++ ;
            if (k == n) break;
        }

        LL res = 0;
        for (int i = 0; i < k; i ++ ) res ^= a[i];
        printf("%lld\n", res);
        return 0;
    }
    ```
2. 动态插入法

    如果只是求最大异或和，其实高斯消元每次 一列列消 $1$ 的操作并不是很优。

    我们换一种思路：我们只要求每个基向量的 $1$ 的最大位置不一样就行了。最大位 $1$ 之后的 $1$ 不要求不重复，最后在取异或和的时候再判重就行了。
    ```
    10011010111101011010101010111110100100010111011011
    01010000001111101000000011011110001010111110000110
    00100011000000111000100011001101101110000110101001
    00011011111110010011101100001101101111010000110110
    00001101101100110001110001011011100101000000101001
    00000110011110100010000011110011101100110010001001
    00000010001111000101011100001111000001110010100111
    00000000110001111110001100110101111101110100000101
    00000000011000010010011011011110100010111101010101
    00000000001010010110111111110110101001011111110111

    和上面同一个样例，此时基向量长这样。
    ```
    怎么判重呢？
    ``` cpp
    ll getMax(){
        ll res=0;
        for(int i=50;i>=0;i--){
            res=max(res,res^a[i]);
        }
        return res;
    }
    ```
    就是比如说：假设我现在处理到第 $i$ 个向量了，异或和目前是
    ```
    111110000 
    ```
    可是我第 $i+1$ 个向量是
    ```
    000010000
    ```
    发现已经重了，本身该第 $i+1$ 个向量负责的那一位 $1$ 已经被前面的向量搞定了。此时 $i+1$ 号向量就直接跳走就行了。

    这样做的正确性很显然：每个向量都有不同的最大值，显然它们线性无关。那么既然是基向量，那线性空间和高斯消元法的线性空间也是一样的。那么高斯消元法是没问题，由此动态插入法也是正确的。

    就此，我们优化掉了高斯消元法消 $1$ 的一层 $O(n)$ 复杂度。

    那么为什么叫动态插入呢？

    因为利用只需要最大 $1$ 不同的特性，每次加入一个新的向量，若当前新向量的最大 $1$ 已经出现过了，就可以用前面的向量把这个最大 $1$ 消掉，直到新向量的最大 $1$ 前面没有或者找不到没有的最大 $1$, 从而可以在 $O( \log n)$ 复杂度内实现动态插入的功能。
    (复杂度是 $O(\log n)$ 是因为向量处理的是一个数的每一位)

    ``` cpp
    void insert(ll x){
        for(int i=50;i>=0;i--){
            if(x>>i&1){
                if(a[i]) x^=a[i];
                else{
                    a[i]=x;
                    return;
                }
            }
            if(!x) return;
        }
    }
    ```

    动态插入法总代码：
    ``` cpp
    #include<iostream>
    #include<cstdio>
    #include<cstring>
    using namespace std;

    const int N=55;
    typedef long long ll;
    int n;
    ll a[N];

    void insert(ll x){
        for(int i=50;i>=0;i--){
            if(x>>i&1){
                if(a[i]) x^=a[i];
                else{
                    a[i]=x;
                    return;
                }
            }
            if(!x) return;
        }
    }

    ll getMax(){
        ll res=0;
        for(int i=50;i>=0;i--){
            res=max(res,res^a[i]);
        }
        return res;
    }

    int main(){
        scanf("%d",&n);
        for(int i=1;i<=n;i++){
            ll x;
            scanf("%lld",&x);
            insert(x);
        }
        printf("%lld\n",getMax());

        return 0;
    }
    ```
## [求第 $k$ 小异或和（AcWing 210. 异或运算）](https://www.acwing.com/problem/content/212/)
首先，由于题目要求要**至少选取一个数**，异或和 $0$ 就变得很特殊——我们不能再无脑什么都不选得到 $0$ 答案了。

那么什么时候原来数的异或和能去到 $0$ 呢？

假设基向量数量为 $x$，

若 $x<n$，则原向量 **线性相关**，因此一定取得到 $0$。

若 $x=n$，则原向量 **线性无关**，则一定取不到 $0$。

由于 $0$ 答案是妥妥的第一小，在 $0$ 答案不合法时，原来求的第 $k$ 小就变成了包括 $0$ 答案的第 $k+1$ 小。代码里特判 $+1$即可。 

其次，此时动态插入法 **不能直接套用**，因为要求第 $k$ 小，**对不同最大值取与不取有严格要求** 。

最后，求第 $k$ 小（这里的 $k$ 已经经过 $0$ 答案特判处理了）有一个 trick，就是吧 $k-1$ 拆成二进制，哪一位是 $1$ 就异或上哪一位对应的基向量。

比如：对于 $k$ 等于 $5$，则 $k-1=4=(100)_2$，我就只需要把最大 $1$ 第三小 的基向量异或上就行了。

再比如：对于 $k$ 等于 $1$，则 $k-1=0=(0)_2$，啥都不异或上，答案直接是 $0$ 即为最小。

为什么这样是正确的？还是因为 **高位在大小比较中对低位是压倒性的**。这就意味着 **仅需且必须把高位确定好，大小比较才是对的**。

1. 高斯消元法代码
    高斯消元只需要小改，最后异或的时候改一下就行了
    ``` cpp
    #include <iostream>
    #include <cstring>
    #include <algorithm>

    using namespace std;

    typedef long long LL;
    const int N = 10010;

    LL a[N];

    int main()
    {
        int T;
        scanf("%d", &T);
        for (int C = 1; C <= T; C ++ )
        {
            printf("Case #%d:\n", C);
            int n;
            scanf("%d", &n);
            for (int i = 0; i < n; i ++ ) scanf("%lld", &a[i]);
            int k = 0;
            for (int i = 62; i >= 0; i -- )
            {
                for (int j = k; j < n; j ++ )
                    if (a[j] >> i & 1)
                    {
                        swap(a[j], a[k]);
                        break;
                    }
                if (!(a[k] >> i & 1)) continue;
                for (int j = 0; j < n; j ++ )
                    if (j != k && (a[j] >> i & 1))
                        a[j] ^= a[k];
                k ++ ;
                if (k == n) break;
            }
            reverse(a, a + k);

            int m;
            scanf("%d", &m);
            while (m -- )
            {
                LL x;
                scanf("%lld", &x);
                if (k < n) x -- ;//如果线性相关，k不用加1；但是转二进制前须减1，故减1；
                if (x >= (1ll << k)) puts("-1");//线性无关，k要+1；同时转二进制减1；故总体不减；
                else
                {
                    LL res = 0;
                    for (int i = 0; i < k; i ++ )
                        if (x >> i & 1)
                            res ^= a[i];
                    printf("%lld\n", res);
                }
            }
        }
        return 0;
    }
    ```

# 一个小问题
