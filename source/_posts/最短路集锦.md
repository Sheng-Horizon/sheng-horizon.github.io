# `Floyd`
就是三层循环
``` cpp
void floyd(){
    for(int k=1;k<=n;k++){
        for(int i=1;i<=n;i++){
            for(int j=1;j<=n;j++){
                d[i][j]=min(d[i][j],d[i][k]+d[k][j]);
            }
        }
    }
}
```
可以这样理解：每次都试图以节点 $k$ 为跳板，全局扩展一次最短路。
所有点对间的最短路是一定会被找到的，因为任意一条最短路都会被在它上面最后被作为跳板的节点确定。

这个时候冒出来一个叫 “传递闭包” 的东西，还以为多唬人呢，结果就是个这：

> 给定一张点数为 $n$ 的有向图的邻接矩阵，图中不包含自环，求该有向图的传递闭包。
>
> 一张图的邻接矩阵定义为一个 $n\times n$ 的矩阵 $A=(a_{ij})_{n\times n}$，其中
>
> $$ a_{ij}=\left\{
> \begin{aligned}
> 1,i\ 到\ j\ 存在直接连边\\
> 0,i\ 到\ j\ 没有直接连边 \\
> \end{aligned}
> \right.
> $$
>
> 一张图的传递闭包定义为一个 $n\times n$ 的矩阵 $B=(b_{ij})_{n\times n}$，其中
>
> $$ b_{ij}=\left\{
> \begin{aligned}
> 1,i\ 可以直接或间接到达\ j\\
> 0,i\ 无法直接或间接到达\ j\\
> \end{aligned}
> \right.
> $$

`Floyd` 弱化一下就出来了。

# `Dijkstra`

`Dijkstra` 适用于图中**没有负权边**的最短路。`Dijkstra` 利用 “处于非负权边的路径上的节点到起点的距离单调不减” 这一特性，使得一旦节点出队，则节点一定得到了最短路径，从而保证算法的复杂度和正确性。

朴素版 `Dijkstra` 的复杂度太难绷了，这里直接写堆优化版的。

如果图共有 $m$ 条边的话，复杂度 $\mathcal{O}(m \log m)$

`Dijkstra` 无向图有向图都能用。因为有边权非负的限制，无向图就成为了有一堆正环的有向图……

```cpp
#include<bits/stdc++.h>
using namespace std;
typedef pair<int,int> pii;

const int N=2e5+10;
int n,m;
int h[N],e[N],ne[N],w[N];
int dist[N];
bool vis[N];
int idx;

void add(int a,int b,int c){
    e[idx]=b;
    ne[idx]=h[a];
    w[idx]=c;
    h[a]=idx++;
}

void dijkstra(){
    memset(dist,0x3f,sizeof dist);
    priority_queue<pii,vector<pii>,greater<pii> >que;
    que.push(make_pair(0,1));
    dist[1]=0;
    while(!que.empty()){
        pii t=que.top();
        que.pop();
        int point=t.second;
        if(vis[point]) continue;
        vis[point]=true;
        for(int i=h[point];i!=-1;i=ne[i]){
            int j=e[i];
            if(dist[j]>dist[point]+w[i]){
                dist[j]=dist[point]+w[i];
                que.push(make_pair(dist[j],j));
            }
        }
    }
}

int main(){
    memset(h,-1,sizeof h);
    scanf("%d%d",&n,&m);
    for(int i=1;i<=m;i++){
        int a,b,c;
        scanf("%d%d%d",&a,&b,&c);
        add(a,b,c);
    }
    dijkstra();
    printf("%d\n",dist[n]==0x3f3f3f3f?-1:dist[n]);
    return 0;
}
```
# `Bellman-ford`
`Bellman-ford` 是一种偏暴力的最短路算法，其操作如下：
```
for(n次)
    for(所有边{a,b,w}) //a为起点，b为终点，w为边权
        dist[b]=min(dist[b],dist[a]+w);
```

最后 `dist[]` 即为从起点到每个点的最短路。

（此时每个点 $x$ 都满足：对于任意一个点 $y$，都有 `dist[x]<=dist[y]+w`，即三角不等式）

便于直观理解，画个动图：

![不要注意细节（确信）](/img/graphGif.gif)

蓝色的是最短路，紫色的是扫到过了的

这样正确性就比较显然了 ~~（尽管不小心把图做成无向图了不过也没事反正没有负环）~~

复杂度最坏 $\mathcal{O}(nm)$，即每次扫描只能拓展一条最短路，每扫一次都扫了 $m$ 条边（图为一条链的情况）

# `SPFA`

## 最短路功能

`SPFA` 是 `Bellman-ford` 的优化，根据动图可以看出来 `Bellman-ford` 每次遍历的很多边由于两端点还没有扫过导致遍历是无效的。

`SPFA` 就用队列解决了这个问题——只有当新的最短路路径被发现后，与新最短路的端点相连的点才有希望被更新。

但是通过一系列惊天地泣鬼神的构造 `SPFA` 也可以被卡到 $\mathcal{O}(nm)$。所以 `SPFA` 只能慎用了。

[「笔记」如何优雅地卡 Spfa](https://www.cnblogs.com/luckyblock/p/14317096.html)

```cpp
void spfa(){
    memset(dist,0x3f,sizeof dist);
    dist[1]=0;
    queue<int> que;
    que.push(1);
    vis[1]=true;
    while(!que.empty()){
        int point=que.front();
        que.pop();
        vis[point]=false;
        for(int i=h[point];i!=-1;i=ne[i]){
            int j=e[i];
            if(dist[j]>dist[point]+w[i]){
                dist[j]=dist[point]+w[i];
                if(!vis[j]){
                    vis[j]=true;
                    que.push(j);
                }
            }
        }
    }
}
```

主函数什么的和 `Dijkstra` 一致

## 判负环功能

负环的存在会造成 `SPFA` 可以无尽地松弛下去。

所以只要松弛次数超过了 $n-1$（$n-1$ 是因为起点显然在最短路里面，所以最坏只需要跑 $n-1$ 次使另外 $n-1$ 个点进入最短路）还可以继续进行的话，那就一定有负环了。

```cpp
int cnt[N];

bool spfa(){
    memset(dist,0x3f,sizeof dist);
    dist[1]=0;
    queue<int> que;
    que.push(1);
    vis[1]=true;
    while(!que.empty()){
        int point=que.front();
        que.pop();
        vis[point]=false;
        for(int i=h[point];i!=-1;i=ne[i]){
            int j=e[i];
            if(dist[j]>dist[point]+w[i]){
                dist[j]=dist[point]+w[i];

                //--------
                cnt[j]=cnt[point]+1;
                if(cnt[j]>=n) return true; //如果松弛次数超了
                //--------

                if(!vis[j]){
                    vis[j]=true;
                    que.push(j);
                }
            }
        }
    }
    return false;
}
```

## 差分约束功能
### 定义

**差分约束系统** 是一种特殊的 $n$ 元一次不等式组，它包含 $n$ 个变量 $x_1,x_2,\dots,x_n$ 以及 $m$ 个约束条件，每个约束条件是由两个其中的变量做差构成的，形如 $x_i-x_j\leq c_k$，其中 $1 \leq i, j \leq n, i \neq j, 1 \leq k \leq m$ 并且 $c_k$ 是常数（可以是非负数，也可以是负数）。我们要解决的问题是：求一组解 $x_1=a_1,x_2=a_2,\dots,x_n=a_n$，使得所有的约束条件得到满足，否则判断出无解。

还记得最短路跑出来的结果是什么吗？

是对于任意一条边 $(a,b,w)$，其中 $a$ 表示起点，$b$ 表示终点，$w$ 表示权值，则 $\mathrm{dist}[b] \le \mathrm{dist}[a] +w$

你看差分约束的结构是不是和 $\mathrm{dist}[]$ 很像？—— $x_i-x_j\leq c_k$

这公式左右两边移一下就是最短路的样子嘛！

$$
x_i\leq x_j+c_k
$$

我们把 $x$ 写作 $\mathrm{dist}$，简直就是直接从 $j$ 到 $i$ 连一条边权为 $c_k$ 的边就行了。

详细情况参考下表：

|         题意         |                      转化                     |               连边              |
| :----------------: | :-----------------------------------------: | :---------------------------: |
| $x_a - x_b \geq c$ |             $x_b \leq x_a+(-c)$             |        `add(a, b, -c);`       |
| $x_a - x_b \leq c$ |              $x_a \leq x_b+c$             |        `add(b, a, c);`        |
|     $x_a = x_b$    | $x_a \leq x_b$ 且 $x_b \le x_a$ | `add(b, a, 0), add(a, b, 0);` |

然后直接上 `SPFA` 跑一遍最短路就行了，有负环就是不存在解，否则 $\mathrm{dist}$ 就是一组解。由于是差分约束，数与数之间只管相对关系，所以 $\mathrm{dist}$ 中的值同加一个 $\Delta d$ 便是通解。

当然你非要用 `SPFA` 跑最长路找差分约束也没问题，只是现在就成了有正环即无解，并且三角不等式变成了 $\mathrm{dist}[b] \ge \mathrm{dist}[a] +w$，需要又推一推。

代码就不写了，和普通 `SPFA` 一模一样。
