虽然只是一个 `普及-` 级知识点，但是好久没用依然忘了

``` cpp
#include<bits/stdc++.h>
using namespace std;
int n,q;
const int N=1e8+10;
bool vis[N];
vector<int> prime;

void get(int x){
    for(int i=2;i<=x;i++){
        if(!vis[i]) prime.push_back(i);
        for(int j:prime){
            if(i*j>x) break;
            vis[i*j]=true;
            if(i%j==0) break;
        }
    }
    return;
}

int main(){
    freopen("test.in","r",stdin);
    freopen("test.out","w",stdout);
	scanf("%d%d",&n,&q);
	get(n);
	for(int i=1;i<=q;i++){
		int a;
		scanf("%d",&a);
		printf("%d\n",prime[a-1]);
	}
	return 0;
}
```

一直容易忘可能是没有完全理解到其原理吧。

对于 $i \times prime[j]$ 这个操作，```if(i%j==0) break;``` 这个语句使得 $i$ 被保证其最小质因子是 $prime[j]$，因为如果它的质因子更小的话那么会更早地 `break`。

那么枚举 $prime[j]$ 及以前的质数就是让乘出来的这个合数的最小质因子更小，从而保证了每一个合数都是由最小质因子筛掉的，从而保证了线性的复杂度。

---


2026/9/17 补充：

```for(int j:prime)``` 有点类似 Python 的 ```for j in prime```, `j` 即为 `prime[]` 的元素, 但为了方便表示依旧把 `j` 表示为 `prime[j]`

由于 $prime[]$ 数组是从小到大遍历的，如果 `i%j==0` 了之后还不 break 的话，$i \times prime[j]$ 这个合数的 **最小质因数** 可就会从 $i$ 中得到了捏。

假设此时 $i \times prime[j] = i' \times prime[a] \times prime[j']$，其中 $i = i' \times prime[a], a<j'$。这个合数其实会在 $i''=i'*prime[j]$ 的时候以 $i'' \times prime[a]$ 的形式被筛掉

因此不 `break` 的话，筛素数就会重复
